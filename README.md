# homebrew-tap

Homebrew tap for h0ck3ystyx applications.

## Installation

### Peekdown

[Peekdown](https://github.com/h0ck3ystyx/peekdown) is a Quick Look extension for previewing Markdown files on macOS.

#### Install

```bash
brew install --cask h0ck3ystyx/tap/peekdown
```

After installation, launch Peekdown.app once to register the Quick Look extensions with macOS. You may need to enable them under System Settings → General → Login Items & Extensions → Quick Look.

#### Upgrade

```bash
brew upgrade --cask peekdown
```

#### Uninstall

```bash
brew uninstall --cask peekdown
```

To remove all associated data:

```bash
brew uninstall --zap --cask peekdown
```
